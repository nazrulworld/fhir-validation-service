## Workflow

- Run `./mvnw verify` before opening a pull request (needs Docker for the Testcontainers tests).
- Features follow the spec-driven flow in [`.specify/memory/constitution.md`](.specify/memory/constitution.md):
  specify → clarify → plan → tasks → implement.
- Record user-visible changes in [`CHANGELOG.md`](CHANGELOG.md).
- Third-party license information is generated by the build. When a new dependency brings a new license, the build
  fails until its text is added under `src/main/resources/META-INF/third-party-licenses/` and its entry is explained in
  `src/main/resources/META-INF/THIRD-PARTY-CLARIFICATIONS.md`.
